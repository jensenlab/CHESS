Stocks

Reagents, species, organisms, and the Stock types that combine them. See the Reagents & Species and Stocks manual chapters. Composition and acid/base chemistry are on the Solution Chemistry page.

CHESSCore.StockComponent — Type
abstract type StockComponent end

Common supertype for anything a Stock can contain and track a quantity of – Reagent (chemical substances: Solid/Liquid/Gas) and Organism. Exists purely as a dispatch/gathering anchor – e.g. so Pourfecto's planning code can enumerate everything in a Stock uniformly – not as a shared-behavior contract: StockComponent has no fields or methods of its own, and Reagent's chemistry-specific machinery (molecular weight, density, dissolution, PubChem-backed persistence) is not inherited by Organism, nor is anything organism-specific inherited by Reagent.

CHESSCore.opaque — Constant
opaque

Marker for intentionally undeterminable atomic content: pass it where a formula string is expected, as in Species("yeast extract",0,CHESSCore.opaque), or write opaque in the formula position of @species and @reagent. Call it with a molar mass, opaque(1415.6u"g/mol"), for content that has no formula but a known average molecular weight (a mixture sold as a salt, or a solution whose stated purity makes its effective molecular weight differ from the compound's). Without a molar mass the species has no molecular weight and no moles are tracked for it.

OpaqueFormula

The type of CHESSCore.opaque, the marker for a species whose atomic content is intentionally not described (an undefined mixture such as yeast extract). It is distinct from a missing formula, which means the formula has not been registered yet. It may carry an average molecular weight, given by calling the marker: opaque(1415.6u"g/mol").

CHESSCore.formula_string — Method
formula_string(counts::AbstractDict{Symbol,<:Integer}) -> String

Write element counts as a canonical formula string in Hill order: carbon first and hydrogen second when carbon is present, then the remaining elements alphabetically (all elements alphabetically when there is no carbon). A count of one is omitted. parse_formula reads the result back to the same counts, so equal formulas always give the same string.

CHESSCore.parse_formula — Method
parse_formula(str::AbstractString) -> Dict{Symbol,Int}

Parse an elemental formula string into a dictionary from element symbol to atom count.

Supported syntax:

  • element symbols (one capital letter, optionally one lowercase letter) with an optional integer count: C6H12O6, NaCl. CO is carbon monoxide and Co is cobalt.
  • groups in parentheses or square brackets with an optional multiplier: Fe(OH)3, K4[Fe(CN)6].
  • hydrate parts joined by a middle dot · or an ASCII period, each with an optional leading integer coefficient: FeSO4·7H2O, FeSO4.7H2O, 2NaOH·H2O.

Elements can appear in any order. A repeated element is summed. Charge is not part of the formula string. Whitespace, fractional coefficients, isotopes ([13C], D, T) and unknown symbols raise an ArgumentError.

CHESSCore.dissolutions — Constant
const dissolutions

Registry mapping a specific Reagent value (e.g. the NaCl returned by @reagent) to its Dissolution. A per-value registry, not per-type dispatch, because individual reagents are themselves named values of a small set of types (Solid/Liquid/Gas) — dispatch on typeof(reagent) cannot distinguish e.g. HCl from NaOH (both Solid). Prefer set_dissolution! over mutating this directly.

CHESSCore.Dissolution — Type
struct Dissolution

Describes the stoichiometric products of a Reagent breaking down into Speciess — e.g. Dissolution(Dict(Na⁺=>1, Cl⁻=>1)) for NaCl, or Dissolution(Dict(glucose_chem=>1)) for a non-dissociating reagent (its own identity). Coefficients must be non-negative – represent an acid/base's hydroxide contribution via OH⁻, not a negative H⁺ count (see net_hydrogen_ion_concentration) – since molecular_weight sums a reagent's registered products directly.

+ and * build a Dissolution from Species values: spc"Na+" + spc"Cl-", or spc"Mg2+" + 2*spc"Cl-". A reagent is defined from one by @reagent or registered with set_dissolution!.

CHESSCore.Reagent — Type
abstract type Reagent end

Represents a physical material: a substance you can weigh out or pipette and store. Reagents identify the materials in the lab's mixtures and solutions, tracked in Stock's SolidDict/LiquidDict.

All Reagent subtypes have four fields utilized by CHESSCore:

  1. name: the name by which the reagent will be referred to
  2. molecular_weight: the reagent's stored molecular weight. For a reagent defined by a formula or a Dissolution, this is the weight derived from it when the reagent was defined, and molecular_weight re-derives it from the registered dissolution whenever one exists. If the weight is unknown, missing.
  3. density: the reagent's density at STP, if known, is used by CHESSCore to facilitate conversions between mass and volume quantities of the reagent. If density is unknown or undefined, it is assigned a value of missing
  4. pubchemid: the reagent's integer PubChem ID, which identifies the reagent's compound in the PubChem database.

See also: Species for what a reagent breaks into once dissolved, @reagent for defining one, and StockComponent for the common dispatch/gathering ancestor Reagent shares with Organism.

CHESSCore.Species — Type
struct Species

Represents a species — what a Reagent behaves as once it's part of a reactive system (e.g. Na⁺, Cl⁻ from dissolved NaCl; or, trivially, glucose's own identity for a non-dissociating reagent). Species values are never added directly to a Stock — they exist purely as the output vocabulary of dissolution (per-Reagent) and Composition (per-Stock), without changing how Stock stores its (undissociated) Reagent components.

A species carries a name, an integer charge (0 for neutral species), and one of three descriptions of its atomic content:

  • an elemental formula string such as "C6H12O6" (see CHESSCore.parse_formula), from which molecular_weight is derived using atomic masses;
  • a stored molecular weight (or missing), for a species whose formula is not registered yet; or
  • CHESSCore.opaque, for a species whose atomic content is intentionally not described.
julia> Species("glucose",0,"C6H12O6")

julia> Species("mystery ion",1,missing)

Unlike Reagent, Species has real value-based equality/hash (not Julia's identity-based default) because dissolutions and the identity-default fallback (see dissolution) routinely construct Species values on the fly, and those must compare equal to independently-constructed-but- identical values for Dict lookups (e.g. Composition/total_concentration) to work correctly. Two species are equal when their name, charge, and formula are equal (and, for species without a formula, their stored molecular weights).

CHESSCore._charge_symbol_candidates — Method
_charge_symbol_candidates(sym::Symbol)

Generate plausible canonical-superscript-charge spellings of sym's plain-ASCII form (e.g. :Na+ -> [:Na⁺]; :Ca2+ -> [:Ca⁺, :Ca²⁺]; Symbol("SO4 2-") -> [:SO4⁻, :SO4²⁻]), superscripting a trailing ASCII +/- and, progressively, 0/1/2 trailing digits before it. Internal whitespace is stripped first (CHESSCore's registered names never contain spaces, even though some display name strings do, e.g. "SO4 2-"). Returns Symbol[] if sym doesn't end in an ASCII +/- at all. Candidates are tried in order (fewest digits superscripted first) by lookup_named_value, which only accepts one that resolves to an actual registered binding – this is what resolves the ambiguity between a charge-magnitude digit (Ca2+ -> Ca²⁺) and a formula digit that happens to precede the sign (H2PO4- -> H2PO4⁻, not H2PO⁴⁻).

CHESSCore.symbol — Method
symbol(x; context=vcat([CHESSCore],CHESSCore.labmodules))

Return the Symbol that x is bound to somewhere in context (a Module or list of Modules, default: CHESSCore plus every module registered via CHESSCore.register_lab) — the reverse of looking a value up via @spc_str/@rgt_str/@org_str. This is the reliable way to get back the identifier you'd use to reference x in code; name is a separate, display-oriented string not guaranteed to correspond to any actual binding (e.g. H⁺ is bound under :H⁺, but name(H⁺) == "H+"). CHESSCore.@reagent — Macro
@reagent labname name type chemistry density pubchemid

Define a new reagent (a physical Solid/Liquid/Gas) and import it into the workspace under labname. The name argument is the display name for the reagent, which can include a larger set of characters and formatting than the labname. For a given reagent, its type parameter should be the phase in which it exists at STP: Solid, Liquid, or Gas.

The chemistry argument says what the reagent is made of, and is one of:

  • an elemental formula string such as "C6H12O6": the reagent dissolves to a single neutral species of the same name with that formula, and its molecular weight is derived from the formula;
  • a Dissolution built from species, such as spc"Fe3+" + 3*spc"Cl-": the reagent breaks into those species, and its molecular weight is derived from them;
  • a molar mass such as 180.16u"g/mol", for a reagent whose formula is not registered yet: its identity species has no formula and keeps this stored molecular weight;
  • missing, when nothing is known about its chemistry; or
  • opaque, for an undefined mixture such as yeast extract whose atomic content is intentionally not described, or opaque(1415.6u"g/mol") for one with a known average molar mass.

The reagent's dissolution is registered with set_dissolution! (discoverable in dissolutions), and is kept with the defining module so it survives precompilation.

Examples:

julia> using Unitful

julia> @reagent glucose "D-glucose" Solid "C6H12O6" 1.2u"g/mL" 5793
D-glucose

julia> @reagent iron_chloride "iron chloride" Solid (spc"Fe3+" + 3*spc"Cl-") 2.8u"g/mL" 24380
iron chloride

julia> @reagent water "water" Liquid 18.015u"g/mol" 1.00u"g/mL" 962
water

julia> @reagent yeast_extract "yeast extract" Solid opaque 1.0u"g/mL" missing
yeast extract

julia> @reagent bleomycin "bleomycin" Solid opaque(1415.6u"g/mol") missing 5360373
bleomycin

julia> molecular_weight(water)
18.015 g mol⁻¹

Reagents can also be defined manually with type constructors.

Example:

julia> water=Liquid("water",18.015u"g/mol",1.00u"g/mL",962)
water

See also: Solid, Liquid, Gas, Dissolution, @species

CHESSCore.@species — Macro
@species labname name charge formula

Define a new Species value (e.g. an ion like Na⁺, or a standalone neutral species) and import it into the workspace under labname. charge is 0 for neutral species. formula is an elemental formula string such as "C6H12O6"; the molecular weight is derived from it. CHESSCore.volume_estimate — Method
volume_estimate(s::Stock)

Return the estimated volume of a Stock s

  • Mixture approximates the volume based on the density of each reagent. Reagents with a missing density are excluded from the sum (rather than propagating missing and zeroing out the whole estimate) – the result is therefore a lower bound, and a warning is emitted when this happens.

CHESSCore._pretty_quantity — Method
_pretty_quantity(q; sigdigits=3) -> String

Display string for q with sigdigits significant figures. Volumes, masses, molar amounts, biomass, mass-per-volume and molar concentrations are rescaled to the metric prefix that puts the number in [1, 1000) – 2.00 mg rather than 0.0 g, 198 μL rather than 0.2 mL – clamped to the smallest and largest prefixes CHESS displays. Any other unit (percent, OD, ...) keeps its unit. Zero keeps q's own unit, and missing displays as "missing".

CHESSCore._reagent_table — Method
_reagent_table(dict::Union{SolidDict,LiquidDict,OrganismDict}, total; digits=2)

Shared logic behind both show(::MIME"text/plain",::Stock) and reagent_display: sort dict's reagents by name and compute each one's amount and concentration relative to total (the stock's overall quantity/volume_estimate), via _relative_amount. Returns (sorted_reagents, amounts, concentrations), all empty if dict is empty. CHESSCore.JensenLabUnits — Module
JensenLabUnits
