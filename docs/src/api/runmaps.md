# RunMaps API Reference

Run maps: runs joined by labeled links, and functions that build them for common control and
duplicate layouts. See [Run Maps](../manual/runmaps.md) for a worked example. The main entry points
are [`RunMap`](@ref), [`link!`](@ref), [`linked_runs`](@ref), and [`schedule_uniform_controls`](@ref).
